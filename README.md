# Recorte

Captura e anotação de tela para Mac.

- Site: https://yanevangelistaa.github.io/recorte-site/
- Baixar a versão mais recente: https://github.com/yanevangelistaa/recorte-site/releases/latest/download/Recorte.dmg

Requer macOS 14 ou mais recente (Apple Silicon). Na primeira abertura, se o macOS bloquear: Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.
